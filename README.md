\# 🤖 AI Interview Question Generator



An AI-powered web application that generates interview questions based on the selected technology, experience level, and number of questions.



\## 🚀 Features



\- Generate interview questions using AI

\- Select technology

\- Select experience level

\- Select number of questions

\- Save generated questions in MySQL

\- View interview question history

\- Delete saved interview questions

\- React-based user interface

\- Spring Boot REST API backend

\- Gemini API integration
